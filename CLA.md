## 7. How to sign

Contributions to this Project are gated by an automated CLA check on each pull
request:

1. Open your pull request as normal.
2. A bot will comment on the PR if you have not yet signed this Agreement.
3. To sign, post a pull-request comment with **exactly** this sentence:

   > I have read the CLA Document and I hereby sign the CLA

4. Your GitHub username and the signing commit are recorded in
   `signatures/version1/cla.json` on the `cla-signatures` branch. You only need
   to sign once; future PRs are recognized automatically.

The Owner is exempt from signing their own CLA.
